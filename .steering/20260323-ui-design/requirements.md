# requirements.md — 20260323-ui-design

## 要求内容

UIデザイン基盤として、全ページ共通のレイアウトコンポーネントを作成する。
デザインガイド（`docs/OSHIATO_UI_Design_Guide.md`）に従ったカラー・フォント・スペーシングを実装に反映する。

## ユーザーストーリー

- 開発者として、全ページに共通のタブバーが表示される状態にしたい
- 開発者として、AppShellコンポーネントで各ページのレイアウトを統一したい
- 開発者として、デザインガイドに沿ったUIコンポーネントの土台が整っている状態にしたい

## 受け入れ条件

- [ ] `TabBar` コンポーネントが作成されており、5タブ（地図・タイムライン・投稿・軌跡・マイページ）が表示される
- [ ] `AppShell` コンポーネントがTabBarを含むレイアウト枠を提供する
- [ ] `app/layout.tsx` にAppShellが組み込まれ、全ページで共通レイアウトが適用される
- [ ] アクティブタブがLavender（#C4B5FD）で表示される
- [ ] `npm run type-check` でエラーが出ない
- [ ] `npm run lint` で警告が出ない
