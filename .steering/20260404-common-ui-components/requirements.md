# 共通UIコンポーネント整備 - 要件

## 目的

既存・今後のページで繰り返し使う「空状態」「ローディング」「通知」の表示を共通コンポーネントとして整備する。Step 4（既存ページUI改善）〜 Step 7（スポット詳細）の基盤となる。

## 対象コンポーネント

### 1. EmptyState
- アイコン + メッセージ + CTAボタン（任意）を表示
- 用途: 投稿なし、推しなし、訪問なし、軌跡なし等
- CTAボタンは任意（ボタンなしでも使える）

### 2. LoadingSpinner
- ページ・セクション読み込み中の統一表示
- 既存のインラインスピナー（各所にバラバラに書かれている）を置き換え可能にする
- サイズバリエーション: small / medium / large

### 3. Toast
- 成功 / エラー / 警告 の3種類
- 画面上部または下部に一時表示 → 自動で消える
- 用途: 投稿成功、チェックイン完了、エラー通知

## 制約
- CSS Modules を使用（プロジェクト規約）
- `'use client'` はコンポーネントファイルに記載（page.tsx には書かない）
- UI_Design_Guide.md のカラー・フォント規約に従う
