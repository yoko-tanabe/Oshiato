# Phase D：公開スポット閲覧 — 要件定義

## 概要

他ユーザーの「公開」スポットをマップや一覧で閲覧できるようにする。
フォロー機能は実装しない（閲覧のみ）。

## タスク一覧

| # | タスク | 内容 | 複雑度 |
|---|--------|------|--------|
| D-1 | 投稿時の公開/非公開設定 | `PostForm` に「公開する / 自分だけ」トグルを追加。DBの `posts.is_public` カラムに保存 | 低 |
| D-2 | 他ユーザープロフィール（`/user/[id]`） | 匿名ネーム・推し一覧・公開スポット一覧を表示。本人確認は auth.uid() で | 中 |
| D-3 | マップに全公開スポットを表示 | 現在は自分のスポットのみ → `is_public = true` の全ユーザースポットをマップに追加 | 中 |
| D-4 | 自分の投稿と他人の投稿の視覚的区別 | ピンデザインや詳細ページで「あなたの投稿」「他のユーザーの投稿」を明確に区別 | 低 |

## 前提条件

- Phase B（認証基盤）完了済み ✅
- Phase C（マイページ・投稿管理）完了済み ✅

## 注意点

- `posts.is_public` デフォルトは `true`（既存の投稿も含め公開側）
- 他ユーザーのプロフィールには「フォロー」ボタンは付けない（Phase J 以降）
- 非公開投稿（`is_public = false`）は RLS で本人以外に見えないようにする

## 完了基準

- [ ] 投稿時に「公開/非公開」を選択できる
- [ ] マップに他ユーザーの公開スポットが表示される
- [ ] 他ユーザーのプロフィールページ（`/user/[id]`）で公開スポット一覧が見られる
- [ ] 非公開投稿が本人以外に見えないこと
