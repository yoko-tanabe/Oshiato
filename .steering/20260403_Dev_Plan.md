### Step 2: 軌跡マップページ (`/trajectory`)

**最優先**: TabBarからアクセスできるのにプレースホルダーしかないため。

#### 新規作成
- `components/trajectory/TrajectoryMap/TrajectoryMap.tsx` + `.module.css`
- `components/trajectory/TrajectoryMap/TrajectoryMap_dynamic.tsx`

#### Supabase に RPC 追加
```sql
CREATE OR REPLACE FUNCTION get_visit_trajectory(input_user_id UUID)
RETURNS TABLE(id UUID, spot_id UUID, oshi_id UUID, lat DOUBLE PRECISION, lng DOUBLE PRECISION, visited_at TIMESTAMPTZ, source TEXT)
AS $$
  SELECT vl.id, vl.spot_id, vl.oshi_id,
         ST_Y(vl.location::geometry) AS lat,
         ST_X(vl.location::geometry) AS lng,
         vl.visited_at, vl.source
  FROM visit_logs vl
  WHERE vl.user_id = input_user_id
  ORDER BY vl.visited_at ASC;
$$ LANGUAGE sql STABLE;
```

#### 修正
- `app/trajectory/page.tsx` — TrajectoryMap をインポート

#### 機能
- フルスクリーン Mapbox 地図（MapView と同じダークスタイル）
- 訪問ポイントを推しテーマカラーの丸で表示
- 時系列順に線で接続（推しごとに色分け）
- データなし時の空状態表示（「まだ軌跡がありません」）
- 統計オーバーレイ（総訪問数 / 日付範囲）
