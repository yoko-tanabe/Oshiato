# 要件: カテゴリ見直し・期間導入・マップフィルター・ナビ改善・レインボーピン・UI改善

## 背景

Phase 1完了後、Web版の実用性を高めるための改善。投稿のカテゴリ体系を整理し、「いつまで見られるか」という期間概念を導入することで、ユーザーが近くで今日・明日見られるスポットを探せるようにする。

## 要件一覧

### R-1: カテゴリの見直し

現在の5カテゴリ（目撃/コラボカフェ/イベント/ショップ/その他）を4カテゴリに整理する。

| 値 | ラベル | 説明 |
|---|---|---|
| `ooh` | 広告（OOH） | 屋外広告、看板、ラッピングなど |
| `popup` | ポップアップ | コラボカフェ、期間限定ショップなど |
| `event` | イベント | ライブ、握手会、ファンミなど |
| `other` | その他 | 常設ショップ、聖地など |

既存データの移行: `collab_cafe` → `popup`、`shop` → `other`

### R-2: 期間（有効期限）の導入

各投稿に「いつからいつまで見られるか」を設定できるようにする。

| カテゴリ | デフォルト | 手動変更 |
|---|---|---|
| 広告（OOH） | 自動設定（投稿日の週の月曜〜日曜） | 終了日の延長のみ可能 |
| ポップアップ | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |
| イベント | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |
| その他 | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |

### R-3: マップの期間フィルター

地図上で期間を絞り込み、「今日」「明日」「今週」などで見られるスポットを検索できるようにする。

### R-4: 訪問ログへのアクセス改善

軌跡タブ内にタブ切り替えUIを設置し、「軌跡マップ」と「訪問ログ」を切り替え可能にする。現在 `/visits` はTabBarからアクセスできない。

### R-5: チェックイン時のレインボーカラーピン

チェックイン済みスポットのマップピンをレインボーカラー（グラデーション）で表示し、訪問済みであることを視覚的に示す。

### R-6: UI改善（追加対応）

実装中に発見・要望があった以下のUI改善を対応する。

- **カテゴリ選択のハイライト強化**: 選択中のカテゴリボタンが視覚的に判別しづらいため、紫背景+白文字+太字でハイライト
- **カレンダーアイコンの白色化**: 期間入力のdate inputのカレンダーアイコンがダークテーマで見えないため白に変更
- **EXIFメッセージのアイコン改善**: 絵文字（📍⚠️）をlucide-reactのモノトーンアイコン（MapPin, AlertTriangle）に変更
- **PC版HEICプレビュー対応**: PCブラウザ（Chrome等）ではHEIC形式の画像プレビューが表示されないため、heic-decodeでデコードしてプレビュー生成する機能を追加

### R-7: 推しカラー選択の拡張

- デフォルトのプリセットカラー（8色）に加え、「もっと選ぶ」をクリックするとPowerPoint風のカラーピッカー（色相バー + 明度バー）で自由に色を選択できるようにする
- 色相（0〜360度）と明度（20%〜90%）の2軸で、事実上無限の色を選択可能
- 同一ユーザーが既に使用済みのカラーは選択不可（プリセットはグレーアウト、ピッカーは「使用済み」表示）
- バーはマウスドラッグ・タッチスライド両対応
