### 0-2. 期間（有効期限）の導入

投稿に「いつまで見られるか」の期間概念を追加。既存の`start_date`/`end_date`カラムを活用する。

**期間の設定ルール:**

| カテゴリ | デフォルト | 手動変更 |
|---|---|---|
| 広告（OOH） | 自動設定（投稿日の週の月曜〜日曜） | 終了日の延長のみ可能 |
| ポップアップ | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |
| イベント | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |
| その他 | ユーザー入力。未入力時は投稿日〜週の日曜日 | 開始日・終了日ともに入力可能 |

**対象ファイル:**
- `apps/web/components/post/PostForm/PostForm.tsx` — 期間入力UIの追加、カテゴリに応じた表示切替
- `apps/web/components/post/PostForm/PostForm.module.css` — 期間入力フィールドのスタイル
- `apps/web/lib/supabase/database.types.ts` — `start_date`/`end_date`はすでに存在（変更不要）

**UI設計:**
- OOH選択時: 開始日・終了日が自動入力され表示（開始日は編集不可、終了日は延長のみ可能）
- その他カテゴリ: 開始日・終了日のdate inputを表示（自由入力）
- 未入力のまま投稿した場合はデフォルト値で自動保存
- 投稿時に`start_date`/`end_date`を計算してDBに保存

**ヘルパー関数（新規）:**
- `apps/web/lib/date/periodHelper.ts` — `getWeekMonday()`, `getWeekSunday()`, `calcDefaultPeriod(category, postDate)`

### 0-3. マップの期間フィルター

地図上で「今日見られるスポット」「明日見られるスポット」などを絞り込める機能。

**UI設計:**
- マップ上部にフィルターバー（横スクロール可能なチップ）
- 選択肢: 「すべて」「今日」「明日」「今週」「カスタム（日付選択）」
- フィルター選択時、`end_date >= 選択日` かつ `start_date <= 選択日` のスポットのみ表示

**対象ファイル:**
- 新規: `apps/web/components/map/MapFilter/MapFilter.tsx` + `.module.css`

## 各ステップ完了時の確認事項

1. `npx next build` — TypeScript / ESLint エラーなし
2. `npm run dev` — ブラウザで動作確認
3. モバイルサイズ（375px幅）で表示が崩れないこと
4. カテゴリ変更後: 既存投稿が正しいカテゴリで表示されること
5. 期間フィルター: 期限切れスポットがフィルターで非表示になること
6. チェックイン後: マップ上のピンがレインボーカラーになること
7. 軌跡タブ: タブ切り替えで訪問ログが表示されること
