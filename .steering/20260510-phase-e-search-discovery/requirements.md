# Phase E 要件定義

## 概要

Phase E では「知らないスポットを発見できる」機能を実装する。  
検索機能（E-1〜E-3）と推しレコメンデーション（E-4〜E-6）の2本柱。

---

## E-1：検索ページ（`/search`）

### ユーザーストーリー

- 「この推しのスポットを全部見たい」
- 「"渋谷" に関係するスポットを探したい」
- 「ライブ会場のスポットだけ絞り込みたい」

### 機能要件

| # | 要件 |
|---|------|
| E-1-1 | キーワード（スポット名・投稿コメント）でフリーテキスト検索できる |
| E-1-2 | 推し名で絞り込み検索できる（ドロップダウン or チップ選択） |
| E-1-3 | カテゴリ（ooh / popup / event / other）で絞り込みできる |
| E-1-4 | 検索結果はカード形式で一覧表示する（スポット名・投稿者・推し名・写真） |
| E-1-5 | 検索結果のカードをタップするとスポット詳細（`/spot/[id]`）に遷移する |
| E-1-6 | 検索結果ゼロ件のときは「見つかりませんでした」の空状態を表示する |
| E-1-7 | 未ログインユーザーは検索結果（公開スポットのみ）を閲覧できる |

### 検索対象

- `posts` テーブルの `comment` カラム（ILIKE検索）
- `spots` テーブルを経由した位置情報（表示のみ）
- `oshis` テーブルの `name` / `group_name`（推し名フィルター）
- `is_public = true` の投稿のみ対象

## E-2：近くのスポット表示

### ユーザーストーリー

- 「今いる場所の近くに推しのスポットはある？」

### 機能要件

| # | 要件 |
|---|------|
| E-2-1 | `/search` ページ内に「近くのスポット」セクションを設ける |
| E-2-2 | 現在地取得後、半径500m以内の公開スポットを一覧表示する |
| E-2-3 | 既存の `find_nearby_spot` RPC（半径50m）は投稿チェック用なので別途クエリを書く |
| E-2-4 | 位置情報の許可がない場合は「位置情報を許可してください」のメッセージを表示する |

---

## E-3：推し別スポット一覧（`/oshi/[id]/spots`）

### ユーザーストーリー

- 「推しAのスポットを地図ではなく一覧で見たい」
- 「他のファンが投稿したスポットも含めて全部見たい」

### 機能要件

| # | 要件 |
|---|------|
| E-3-1 | `/oshi/[id]/spots` でその推しに紐づく公開スポットを一覧表示する |
| E-3-2 | ページ上部に推し名・グループ名・アイコン色を表示する |
| E-3-3 | スポットのカードをタップすると `/spot/[id]` に遷移する |
| E-3-4 | 既存の `/oshi` ページの各推しカードからリンクで遷移できる |

## E-4：PostgreSQL関数 `get_recommended_spots`

### ロジック

協調フィルタリング（SQL集計のみ・外部ML不要）：

1. 自分の推しリスト（`user_oshis where user_id = me`）を取得
2. 推しが被る他ユーザーを「類似ユーザー」として集計
3. 類似ユーザーが推している、かつ自分が未登録の推しをスコアでランキング（上位5件）
4. 上位5件の推しの公開スポットを返す

### 入出力

- 入力: `target_user_id UUID`
- 出力: `spot_id, latitude, longitude, oshi_id, oshi_name, group_name, category, score, reason_count`

詳細SQLは `docs/OSHIATO_API_Specification_v5_1.md` セクション9 参照。

## E-5：マップへの「おすすめスポット」表示

### 機能要件

| # | 要件 |
|---|------|
| E-5-1 | マップに「おすすめ」スポットを特別なピン（星アイコン ⭐ or 別色）で表示する |
| E-5-2 | おすすめピンは通常ピン・チェックイン済みピンと視覚的に区別できる |
| E-5-3 | おすすめピンをクリックするとポップアップを表示する |
| E-5-4 | レコメンドデータが0件のときはおすすめピンを非表示にする（フォールバック） |

---

## E-6：レコメンド理由テキスト

### 機能要件

| # | 要件 |
|---|------|
| E-6-1 | おすすめポップアップに「同じ好みの N 人が推しています」を表示する |
| E-6-2 | `reason_count` の値を N に使う |

---

## 非機能要件

| 項目 | 要件 |
|------|------|
| 認証 | E-1〜E-3 は未ログインでも公開スポットを閲覧可能。E-4〜E-6 はログイン必須 |
| パフォーマンス | 検索クエリは `posts.comment` に `ILIKE '%keyword%'` を使用（Phase G でインデックス最適化予定） |
| RLS | 検索・一覧はすでに有効な RLS（`is_public = true OR auth.uid() = user_id`）を利用 |
| モバイル | 375px幅で崩れないこと |
