# 手動位置指定機能 - 要件

## 背景
現在、投稿時にEXIF GPS情報がない写真をアップロードすると投稿できない。
位置情報なしの写真でも、ユーザーが手動で場所を指定して投稿できるようにしたい。

## 機能要件

### 1. 住所検索（Geocoding）
- テキスト入力欄に住所や場所名を入力
- Mapbox Geocoding APIで候補を表示（サジェスト）
- 候補を選択すると緯度・経度を取得し、地図上にピンを表示

### 2. 地図タップで位置選択
- Mapbox地図を表示し、タップした位置の緯度・経度を取得
- ピンをドラッグして微調整可能

### 3. 投稿フローへの統合
- EXIF GPS情報がない場合のみ、位置指定UIを表示
- EXIF GPS情報がある場合は従来どおり自動取得
- 手動指定した座標は EXIF座標と同じ扱いで `findOrCreateSpot` に渡す

## 非機能要件
- Mapbox Geocoding API の無料枠内（月10万リクエスト）で運用
- モバイルファースト（375px幅で操作しやすいこと）
