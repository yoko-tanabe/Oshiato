# requirements.md — 20260323-map-display

## 要求内容

マップ画面（`/`）にMapbox GL JSを使った地図を表示する。
UIデザインガイドに沿ったダークテーマで、スポットピンと現在地ボタンを実装する。

## ユーザーストーリー

- ユーザーとして、アプリを開いたらすぐに地図が表示されてほしい
- ユーザーとして、現在地ボタンを押したら自分のいる場所に地図が移動してほしい
- ユーザーとして、Supabaseに登録されたスポットがピンで表示されてほしい

## 受け入れ条件

- [ ] `mapbox-gl` がインストールされている
- [ ] `MapView` コンポーネントが地図を表示する
- [ ] 地図スタイルはダークテーマ（Mapbox Dark）
- [ ] 現在地ボタンが表示され、押すと現在地に移動する
- [ ] Supabaseの `spots` テーブルからスポットを取得してピンを表示する
- [ ] `npm run type-check` でエラーが出ない
- [ ] `npm run lint` で警告が出ない
