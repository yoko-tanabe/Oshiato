# 既存ページUI改善 - 要件

## 目的

Step 3 で作成した共通UIコンポーネント（EmptyState / LoadingSpinner / Toast）を既存ページに適用し、全体の品質を底上げする。

## 対象

### 2-1. TabBar の改善
- 非アクティブタブの色を `#444444` → `#808080` に変更（コントラスト改善）
- ラベルサイズを `9px` → `11px` に拡大
- アクティブタブに下線インジケーター追加

### 2-2. マップページ (`/`)
- コメントアウトされた古いコードを削除（現状なし→console.log の削除）
- 地図読み込み中の LoadingSpinner 表示
- 位置情報エラー時のユーザー向けメッセージ追加

### 2-3. タイムライン (`/timeline`)
- EmptyState コンポーネントで空状態を改善
- LoadingSpinner で読み込み中表示を改善
- グリッド間隔の調整（`3px` → `4px`）
- 月ヘッダーの視覚的な区切り強化
- 画像読み込み失敗時のフォールバック追加

### 2-4. 投稿フォーム (`/post/new`)
- 投稿成功時の Toast 表示追加

### 2-5. 推し管理 (`/oshi`)
- LoadingSpinner で読み込み中表示追加
- EmptyState で空状態を改善
- 推し追加成功時のフィードバック追加（Toast）
