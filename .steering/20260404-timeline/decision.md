# Decision

## 決定事項

### 1. 自分の投稿のみ表示
- **決定**: `user_id` でフィルタし、自分の投稿のみ表示
- **理由**: Phase 1 はソーシャル機能なし。グローバルタイムラインは Phase 3 以降

### 2. `<img>` タグを使用
- **決定**: `next/image` ではなく標準の `<img>` タグを使用
- **理由**: Supabase Storage の外部URLに対し `next/image` は `next.config.js` でドメイン設定が必要。既存コード（MapView のポップアップ等）も `<img>` を使用しており一貫性を保つ
- **代替案**: `next/image` で最適化（Phase 3 以降で検討）

### 3. ページネーションなし
- **決定**: 初回ロードで最大100件取得、無限スクロールは実装しない
- **理由**: Phase 1 プロトタイプでは十分。データ量が増えた時点で追加

### 4. タイルタップは未実装
- **決定**: タイルをタップしても遷移しない
- **理由**: スポット詳細ページ（`/spot/[id]`）がまだスタブのため。詳細ページ実装後に追加

### 5. タイムラインを先に実装（スポット詳細より優先）
- **決定**: スポット詳細は後回しにし、タイムライン → チェックイン → 訪問ログ → 軌跡マップの順で進める
- **理由**: 「最低限人に見せられる」状態にするため、外枠機能を先に完成させる方針
