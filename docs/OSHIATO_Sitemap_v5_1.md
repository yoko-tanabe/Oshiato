## 1. プラットフォーム別役割

### 1.1 概要

**iOS版がメインプロダクト。** Web版はiOS版開発に先行して機能・UXを検証するための先行実装版。

```

│                    プラットフォーム役割分担（v6.0）               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Web版（先行実装・検証用）        iOS版（メインプロダクト）       │
│  ┌─────────────────────┐        ┌─────────────────────┐        │
│  │  • 機能・UX検証      │        │  • 全機能を最高品質  │        │
│  │  • 試用・フィードバック│       │  • 位置情報フル活用  │        │
│  │  • スポット共有閲覧  │        │  • カメラ連携       │        │
│  │  • 投稿・推し管理    │        │  • プッシュ通知     │        │
│  │  • レコメンデーション│        │  • ジオフェンス     │        │
```

## 2. Phase別画面構成

### 2.1 Phase A（完了済み）: Web版プロトタイプ

実装済みの7画面。

```
oshiato.app/
│
├── / .................................................... マップ画面（メイン）
│   ├── 地図表示・スポットピン・現在地ボタン
│   ├── 推しフィルター・カテゴリフィルター・期間フィルター
│   └── おすすめスポットピン（Phase E追加予定）
│
├── /spot/:id ............................................ スポット詳細
│   ├── 写真一覧（言葉オーバーレイトグル付き）（Phase F追加予定）
│   ├── スポット情報・投稿一覧
│   └── チェックインボタン
│
├── /post/new ............................................ 投稿画面
│   ├── 写真選択（EXIF抽出）
│   ├── 位置情報（自動入力 or 手動ピッカー）
│   ├── 推し選択・カテゴリ・期間
│   └── 推しの言葉入力（任意）（Phase F追加予定）
│
├── /timeline ............................................ タイムライン
│   └── 投稿一覧（無限スクロール）（Phase G追加予定）
│
├── /oshi ............................................... 推し管理
│   ├── 推し一覧・推し追加・テーマカラー設定
│
├── /visits ............................................. 訪問ログ
│   └── 訪問履歴一覧（月別グループ）
│
└── /trajectory ......................................... 軌跡（タブ切り替え）
    ├── [タブ: 軌跡マップ]（足跡・糸・推し別フィルター）
    └── [タブ: 訪問ログ]

```

```
│
```

```
    └── 公開スポット一覧
```

- `/post/new`: 公開/非公開の選択肢を追加
- `/`（マップ）: 全ユーザーの公開スポットを表示

**Phase D 新規画面数: 1画面**

---

### 2.5 Phase E: 検索・ディスカバリー＋推しレコメンデーション

```
oshiato.app/
│
└── /search .............................................. 検索・ディスカバリー ← NEW
    ├── キーワード・推し名・カテゴリで検索
    ├── 近くのスポット一覧
    └── 推し別スポット一覧
```

既存画面への変更:
- `/`（マップ）: 「おすすめスポット」ピンをオーバーレイ表示（⭐推しレコメンデーション）
  - ポップアップ: 「同じ好みのユーザー X 人が推しています」

**Phase E 新規画面数: 1画面**

---

### 2.6 Phase F: 推しの言葉オーバーレイ

新規ページは追加せず、既存画面を拡張:

- `/spot/:id`（スポット詳細）
  - 近接時に言葉が降ってくるアニメーション表示（⭐スポット接近トリガー）
  - 写真に言葉を合成する「オーバーレイ ON/OFF」トグル
  - 合成した画像のダウンロードボタン
- `/post/new`（投稿フォーム）
  - 「推しの言葉を残す（任意）」入力フィールドを追加

**Phase F 新規画面数: 0（既存画面を拡張）**

---

### 2.7 Phase G: パフォーマンス最適化

新規ページなし。既存画面の内部改善:
- `/timeline`: 無限スクロール
- `/visits`: 無限スクロール
- `/`（マップ）: クラスタリング改善
