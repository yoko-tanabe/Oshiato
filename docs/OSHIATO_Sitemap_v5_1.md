## 6. URL設計

### 6.1 Web版URL

| 画面 | URL | 認証 |
|------|-----|------|
| LP | / | 不要 |
| ログイン | /auth/login | 不要 |
| マップ | /map | 不要（閲覧のみ） |
| スポット詳細 | /map/spot/:id | 不要 |
| 投稿 | /post/new | 必要 |
| タイムライン | /timeline | 不要 |
| 軌跡マップ | /trajectory | 必要 |
| DM | /dm | 必要 |
| マイページ | /mypage | 必要 |

### 6.2 ディープリンク（iOS）

| パス | 説明 |
|------|------|
| oshiato://map | マップを開く |
| oshiato://map/spot/:id | スポット詳細 |
| oshiato://post/:id | 投稿詳細 |
| oshiato://dm/:roomId | DMチャット |
| oshiato://trajectory | 軌跡マップ |
